# Utförda engångsskript

Migreringar som redan är körda. De ligger kvar för att visa hur en ändring
gjordes, inte för att köras igen.

Kör dem inte utan att först läsa vad de gör. Flera av dem skriver om innehåll,
och alla är inte idempotenta.

De utesluts ur `claude-context.md` av samma skäl: ett utfört migreringsskript i
ögonblicksbilden ser ut som ett aktuellt verktyg.
